Hackercons Roulette API

Hackercons Roulette API is the catalog behind the hackercons-roulette player.

It collects conference talks from several open sources and stores them in a catalog. It serves random clips, a guessing quiz, and a list of sources. It also records clips that fail to play so they stop being served. It refreshes its catalog every six hours.

The repo is checked every morning by Control Troll.

Latest change: Created the clip catalog backend. A fix the same day made the random pick truly random.
